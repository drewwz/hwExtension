# 开售点按

一个 Chrome / Edge 扩展。它在你设定的本地时间，于已经打开的华为商城商品页上，代替手点官方按钮。

购买按钮只点 **1** 次。之后如果页面出现「提交订单」或「确认订单」，再点 **1** 次。插件不向商城发送下单请求，不绕过排队、签名或验证码，也不代你付款。

能省下的是你自己看到按钮后的反应时间。资格仍由华为商城的开售规则决定：抢购商品要在开售时间点出订单号；预约申购则与点击快慢无关。

## 使用前

1. 用准备购买的华为账号登录 [华为商城](https://www.vmall.com/)。
2. 打开目标商品页，选好版本和颜色，确认默认地址和支付方式。
3. 把电脑时间设为自动同步。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页：`chrome://extensions` 或 `edge://extensions`。
2. 打开「开发者模式」。
3. 选择「加载已解压的扩展程序」，指向本仓库的 `extension` 目录。
4. 回到商品页并刷新一次。
5. 点击工具栏里的「开售点按」，核对开售时间（默认 `2026-10-03 10:08:00`，按这台电脑的本地时间），然后点「开始等待」。
6. 把商品页留在前台，直到状态变成「已点购买」或「已点提交」。付款请自己完成。

「查找当前页按钮」只会标出匹配的按钮，不会点击。含「支付」「付款」的按钮会被拒绝，定金和付款需要你自己确认。

页面若弹出验证码，或状态变成「需要手点」，说明页面没有接受这次点击，请直接用手点。

## 本地测试

```bash
npm install
npm test
```

测试使用本机的 Google Chrome，确认扩展会点中「立即抢购」和「提交订单」各一次，并且不会点「立即支付」。
