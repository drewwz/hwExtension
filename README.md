# 开售点按

一个 Chrome / Edge 扩展。它在华为商城商品页上代替手点：刷新后重新选择规格，等「立即购买」可以点时点一次；排队结束后，在确认订单页点一次「提交订单」。

插件不向商城发送下单请求，不打开写好参数的确认订单链接，不绕过排队，也不代你付款。

## 使用前

1. 用准备购买的华为账号登录 [华为商城](https://www.vmall.com/)。
2. 打开目标商品页，选好版本和颜色，确认默认地址和支付方式。
3. 把电脑时间设为自动同步。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页：`chrome://extensions` 或 `edge://extensions`。
2. 打开「开发者模式」。
3. 选择「加载已解压的扩展程序」，指向本仓库的 `extension` 目录。
4. 回到商品页并刷新一次。如果点「开始等待」仍提示页面没准备好，在扩展管理页重新加载本扩展，并允许它访问华为商城。版本 1.2.1 起，点「开始等待」时会把脚本挂进当前商品页。
5. 点击工具栏里的「开售点按」。默认时间是这台电脑本地时间的 `2026-10-03 10:08:00`。默认规格是「曜石黑」和「16GB+1TB 典藏版」。先点「开始等待」。倒计时结束前可以刷新商品页，刷新后会重新点这两项。时间一到就不要再按 F5，留在这一页。页顶会出现一条状态。开售后两分钟内如果又刷新了，插件还会再找一次购买按钮；超过两分钟，页顶会显示这次刷新已经太晚。
6. 页面上要已经显示你的收货地址。如果仍是「请选择收货地址」，插件不会点购买。
7. 插件里的「自动点提交订单」默认开着。关掉后只点「立即购买」，确认页不再代点。到点后，只有按钮文字变成「立即购买」才会点。确认订单页可以在当前标签打开，也可以是新窗口。自动提交开启时，进入确认页后每 30 毫秒检查一次：提交按钮、价格，以及页面自己的风控脚本都就绪后，才点一次「提交订单」。失败的下单请求不会被当成“已经初始化好”。如果弹出「火爆销售中」，会点「知道了」；如果弹出「本次没有买到」并带「返回」，会点「返回」，不会点「再试试」。关掉之后先等页面稳住再提交，并一直重复，直到某一次不再弹出，或你在插件里点「停止」。付款请自己完成。
8. 「开始补货」用来守退单后随机放出的货。打开典藏版商品页再点它。插件会等页面上出现规格，再决定要不要买；没有有货颜色就隔 30 到 50 毫秒再刷新，不会在页面还是空的时候按固定间隔硬刷。无货时购买按钮是不可点的「缺货」，有货后才变成「立即购买」。看到货后，会选中「16GB+1TB 典藏版」和任意一个有货的颜色，点「立即购买」。点完如果还在商品页，短暂的排队弹窗会留着，等它自己进订单页。若这一步就弹出货又没了（售罄、库存不足、本次没有买到这类），会点「知道了」或「确定」关掉，不会点「返回」，然后仍在这个商品页刷新下一轮。进入确认页后继续提交。弹出「火爆销售中」就关掉继续点；弹出「本次没有买到」就回到商品页再刷下一轮。顺利进入支付页后，按电脑当前音量循环响铃，提醒你在 8 分钟内付款。点「停止」会停刷并关掉铃声。电脑需要醒着、系统没有静音；商品页尽量留在前台，否则浏览器会把后台刷新拖慢。

「查找当前页按钮」只会标出匹配的文字，不会点击。含「支付」「付款」的按钮会被拒绝。

页面若弹出验证码，或状态变成「需要手点」，说明页面没有接受这次点击，请直接用手点。当前这款商品页上的购买按钮是「暂时缺货」，页面里还没有「立即购买」。只有开售后按钮变成这四个字，插件才会点。

## 本地测试

```bash
npm install
npm test
```

测试使用本机的 Google Chrome，确认扩展会点中「立即抢购」和「提交订单」各一次，并且不会点「立即支付」。
